# Documentation index

AI Routing Gateway is an embeddable, dependency-free Python decision plane for
explainable model/tool routing and gated specialist-agent workflows. It is an
alpha library, not a hosted provider gateway.

## Authoritative documents

- README.md: installation, examples, public commands, and safety boundaries.
- docs/architecture.md: component boundaries and control/data flow.
- docs/technical-overview.md: package map, interfaces, technology, and API.
- docs/ROUTING_STRATEGY.md: product differentiation and routing research.
- docs/LLM_COUNCIL_REVIEW.md, docs/TEAM_SDK.md, docs/RELEASING.md: specialist contracts.
- AGENTS.md, .ai/, and .agents/skills/document-ai-gateway: local agent rules.
